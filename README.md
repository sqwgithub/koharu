# Koharu 中文翻译与排版分支

本分支基于 [koharu-rs/koharu](https://github.com/koharu-rs/koharu)，用于特化中文翻译的排版。面向日漫汉化中的竖排对白、角色称呼和逐页校对。安装、模型、硬件要求和构建步骤见[上游项目说明](https://github.com/koharu-rs/koharu/blob/main/README.md)。

## 分支修改

### 建项目与运行翻译

- **关联原图**。可从 ZIP、CBZ 或图片目录新建项目，选择位置保存 `.khr`。项目引用原图，原图搬家后可用「重新定位原图」恢复关联。已有 `.khr` 可通过「打开项目文件」打开。
- **选择范围与续跑**。可处理整个项目、所选页面，或从最后一个所选页之后开始。中断后点「继续」，程序会检查所选阶段已有的结果，接着处理未完成的页和文字块。修补与翻译并行时，活动面板显示仍在运行的阶段，并随页面完成更新进度。
- **OpenCode Go 与多页翻译**。可选用 OpenCode Go 作为模型提供商。其 DeepSeek V4 系列在纯文本模式下按容量合并多页请求，参考前文译文和适用术语。可见文字块沿用「故事」面板的编号，程序核对返回的编号和原文，缺项或错位时会重试。每批校验通过后写回，中断时已写入的批次会保留。
- **快速翻译**。在翻译设置中开启后，重复的拟声词按原文去重，单独成批翻译。译名保存到「全局词表 → 拟声词译名」，可修改或移除。同一源语言和目标语言的其他项目可直接复用。普通对白、没有命中词表且只出现一次的拟声词继续按上下文翻译。

### 术语与人工校对

- **译文存疑**。翻译模型可以随译文给出需要核对的原因。在「建议确认」可跳到原文字块、编辑或直接确认当前译文。
- **字色校对**。「建议确认」折叠隐藏文字，并略过接近黑白或已人工处理的字色。「编辑 → 统一字色」可在已纳入页面内批量调整有检测记录的文字块，或还原检测时的原始字色；详细模式可设置每个 RGB 通道的阈值和两种目标色。
- **手动候选译名**。在项目的「术语候选」中，展开原词即可输入备选译名。按 Enter 或点加号添加，点击译名选用，点 × 移除手动候选。选中译名后，点「应用到已有译文」会跳过已排除的句子。整块旧译名可直接替换；句中的旧译名由术语分析模型定位，再由程序核对并替换为选中的译名。定位有疑义时，可在「建议确认」跳到原句，核对后修改或保留现译。一次应用可整体撤销。候选列表随项目保存。此版首次写入旧项目时会升级为 1.6 格式。
- **原文提取与术语分析**。在「术语表」中提取全篇 OCR 原文，可导出含页码和图层 ID 的 JSON。分析会跨页提取人物、地点和术语，汇总有冲突的候选，并复核假名称呼是否对应已出现的汉字人名。术语分析可单独选择模型、思考强度和提示词。
- **全局词表、项目词表与禁翻表**。同一原文优先采用项目词条。可以统一译名、给词条附上 LLM Wiki 链接，也可以只对某一句排除该词条。禁翻支持原样保留词句，或给整个文字块保留原字。翻译后可用「检查译文」核对用词是否一致。
- **建议确认**。点击证据可跳到对应页和文字块。人名称呼和译文修订都可修改后接受或驳回。确认的称呼写入术语表，译文修订只应用于对应文字块。自动检测到纯黑、纯白以外的字色也会列在这里，可保留当前色或将译文改为黑色、白色。

### 中文竖排与图层

- **对白字号与断列**。译文字号参考原文字宽和同页对白。整组文字结合气泡轮廓居中，竖排优先在标点处断列，尽量均衡列长，窄气泡中的短句保留单列。同一气泡内并排的竖排文字块分别划定排版区域，减少译文绕到相邻列下方。气泡外对白可自动加白色描边。旧项目可通过「编辑 → 更新项目对白的自动字号」重算，支持撤销。
- **拟声词显隐**。可按本页或全项目切换拟声词，各图层的眼睛随之更新，也能单独调整。首次 OCR 会将误标为拟声词的日语感叹词「すごい」纠正为普通对白。已有项目可在图层面板手动更改。
- **单页显隐与导出**。在左侧「页面」关闭眼睛，会将该页排除出流水线，同时在画布和缩略图中隐藏已有译文与修补。重新打开即可恢复各图层原先的显隐状态。导出分层 PSD 时，隐藏的译文仍可编辑。
